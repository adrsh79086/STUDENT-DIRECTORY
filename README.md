# Smart Tracker

Smart Tracker is a task management application where users can register, login, and manage their tasks.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router
- Axios
- Formik & Yup
- Material UI DataGrid

### Backend
- NestJS
- TypeScript
- MongoDB
- Mongoose
- JWT
- bcrypt
- class-validator

## Features

- User Registration & Login
- JWT Authentication
- Protected Routes
- Create, Read, Update & Delete Tasks
- Task Search & Filters
- Task Details
- User-specific Tasks
- Pagination
